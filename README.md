# DevBuddy AI

Assistente de estudos de programação em Python, feito para ajudar iniciantes a entender código, aprender conceitos e resolver erros.

## Status

Em desenvolvimento inicial. Nenhuma funcionalidade pronta ainda.

## Objetivo da primeira versão (MVP)

Uma interface de linha de comando em que o usuário cola um trecho de código e recebe uma explicação didática.

## Funcionalidades planejadas

- Explicação de trechos de código
- Explicação de conceitos com exemplos
- Ajuda com mensagens de erro
- Exercícios com níveis de dificuldade
